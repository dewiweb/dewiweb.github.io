## Présentation

**Horloge OSD always-on-top pour Linux X11** — l'outil de régie qui garde l'heure sous les yeux sur n'importe quel poste, au-dessus de toutes les fenêtres. Configurable, légère, universelle.

## Fonctionnalités

- Affichage au-dessus de toutes les fenêtres (overlay OSD)
- **Click-through** : la souris traverse l'horloge
- Déplaçable à la souris, icône système tray
- Paramétrage complet : police, taille, couleurs, opacité, format strftime, position (9 zones), choix de l'écran
- Prévisualisation en temps réel, configuration persistante
- Compatible Cinnamon, GNOME, KDE, XFCE, MATE, i3, Openbox…
