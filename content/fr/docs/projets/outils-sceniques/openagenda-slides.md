## Présentation

Généralisation de [nextevents](/docs/projets/outils-sceniques/nextevents/) : transforme **n'importe quel agenda OpenAgenda public** en diaporama d'écrans — une diapositive par événement (image, date, lieu, tarif, public…) pour téléviseurs, bornes et panneaux d'affichage, en **16:9, 9:16 portrait ou A4** imprimable.

Aucune compétence technique nécessaire : télécharger, indiquer l'agenda, cliquer sur **Générer**.

## Fonctionnalités

- Application desktop **Qt**, portable Windows et Linux (AppImage) — sans installation
- Une diapo par événement, charte graphique soignée
- Formats paysage, portrait et imprimable
- Binaires disponibles dans les Releases GitHub
