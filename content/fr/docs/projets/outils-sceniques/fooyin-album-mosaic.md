## Présentation

Plugin pour le lecteur audio **Fooyin** affichant une **mosaïque infinie de pochettes d'albums** animées — navigation cyclique dans toute la collection.

## Fonctionnalités

- Grille infinie cyclique à taille de cellule adaptative
- Chargement efficace via le `CoverRepository` partagé de Fooyin
- **5 animations** : flip 3D, crossfade, slide, zoom, page curl (+ mode aléatoire, 3 vitesses)
- Nombre de colonnes et couleur de fond configurables
- Placeholder élégant pour les albums sans pochette
