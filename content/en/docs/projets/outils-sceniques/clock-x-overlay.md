## Overview

**Always-on-top OSD clock for Linux X11** — the control-room tool that keeps the time visible on any workstation, above every window. Configurable, lightweight, universal.

## Features

- Displays above all windows (OSD overlay)
- **Click-through**: the mouse passes through the clock
- Draggable, system tray icon
- Full settings: font, size, colors, opacity, strftime format, position (9 zones), screen selection
- Real-time preview, persistent configuration
- Works with Cinnamon, GNOME, KDE, XFCE, MATE, i3, Openbox…
