## Overview

Plugin for the **Fooyin** audio player displaying an **infinite scrolling mosaic of album covers** with animations — cyclic browsing through the whole collection.

## Features

- Infinite cyclic grid with adaptive cell size
- Efficient loading via Fooyin's shared `CoverRepository`
- **5 animations**: 3D flip, crossfade, slide, zoom, page curl (+ random mode, 3 speeds)
- Configurable column count and background color
- Elegant placeholder for albums without covers
