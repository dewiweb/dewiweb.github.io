## Overview

Generalization of [nextevents](/en/docs/projets/outils-sceniques/nextevents/): turns **any public OpenAgenda agenda** into screen slideshows — one slide per event (image, date, venue, price, audience…) for TVs, kiosks and digital signage, in **16:9, 9:16 portrait or printable A4**.

No technical skills required: download, enter your agenda, click **Generate**.

## Features

- Portable **Qt** desktop app for Windows and Linux (AppImage) — no install
- One polished slide per event
- Landscape, portrait and printable formats
- Binaries available in GitHub Releases
